# Teacher Copilot

Приложение для учителей: проверка ученических работ, создание заданий и разбор результатов. Проект тестируют учителя.

[Открыть сайт](https://teachercopilot-three.vercel.app/)

## Что можно делать

- **Проверять работы.** Загружать фото и PDF, добавлять ответы и критерии, просматривать распознанные ответы рядом с оригиналом. Работы могут быть созданы вне приложения.
- **Сканировать стопку.** Камера автоматически снимает неподвижный лист и ждёт его удаления перед следующим. После съёмки нужно просмотреть галерею: подозрительные снимки выделены, их можно заменить или повернуть. Несколько листов можно объединить в одну работу.
- **Начинать с пробной проверки.** Выбрать 3–5 работ, исправить предложения ИИ с пояснениями, проверить предложенные правила и применить их к остальным работам этой проверки.
- **Выбирать самостоятельность ИИ.** Осторожный режим принимает совпадения с эталоном, баланс — ещё и уверенные короткие ответы, быстрый — также развёрнутые ответы по критериям. Режим выбирается перед запуском каждой проверки.
- **Принимать и исправлять оценки.** Подтверждать ответы по одному или группой. Пустые, нечитаемые и неоднозначные ответы требуют отдельного решения. До завершения проверки любой балл можно изменить.
- **Создавать рабочие листы.** Вручную или с помощью ИИ, с несколькими вариантами и экспортом в PDF без ответов для учеников.
- **Смотреть результаты.** Итоговые баллы, проценты, оценки для ФО и контрольных, статистика по заданиям и частые ошибки.
- **Организовывать уроки.** Классы, библиотека заданий, съёмка стопки работ через камеру и Debate Arena с командами, таймером и темами.

В настройках доступны профиль и школа, правила сравнения ответов, шкалы оценок, хранение изображений и уведомления внутри сайта. Есть светлая, тёмная и системная темы.

ИИ предлагает предварительные оценки. Учитель может их исправить и сам завершает проверку. Confidence — самооценка модели, а не гарантия правильного ответа.

## Локальный запуск

Нужны **Node.js 22+**, npm и проект Supabase.

```sh
npm ci
```

Создай `.env.local` по образцу `.env.example` и заполни:

```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
GROQ_API_KEY=your-groq-api-key
```

Ключ Groq нужен для функций ИИ. Модели можно переопределить через `GROQ_MODEL` и `GROQ_VISION_MODEL`; значения по умолчанию есть в `.env.example`. Ключ Groq доступен только серверу; `.env.local` не добавляется в Git.

Для нового проекта Supabase примени **все** файлы из `supabase/migrations` в порядке имён. Описание базы и прав доступа — в [supabase/README.md](supabase/README.md).

В Supabase Auth укажи Site URL: `http://localhost:3000` для разработки или адрес сайта для публикации. В шаблоне письма Confirm signup используй ссылку:

```html
<a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email">
  Подтвердить email
</a>
```

```sh
npm run dev
```

Приложение откроется на [localhost:3000](http://localhost:3000). Для публикации на Vercel задай те же переменные окружения в настройках проекта.

## Разработка

Next.js 16, React, TypeScript, Tailwind CSS, shadcn/ui. Supabase отвечает за авторизацию, PostgreSQL и приватное хранение файлов; Groq — за ИИ.

Страницы находятся в `src/app`, компоненты — в `src/components`, логика — в `src/lib`, серверные действия — в `src/actions`. Доступ к данным ограничен владельцем через RLS.

```sh
npm run lint
npm run typecheck
npm run build
```

## Текущие ограничения

- До 100 листов в проверке и до 10 листов в одной работе. Для автосъёмки нужны неподвижная камера, ровное освещение и пустой кадр между листами. Подсказки качества приблизительные.
- Пробные работы выбираются из разных частей пачки; до распознавания качество ответов неизвестно. Правила подтверждает учитель, они действуют только в этой проверке.
- Debate Arena хранит состояние только в открытой странице; обновление сбрасывает дебаты.
- Интерфейс пока на русском. Казахский и английский запланированы.
- Удаление изображений по сроку хранения запускается при входе на сайт. Фоновый запуск и email-уведомления пока не настроены.
- Доступность ИИ зависит от лимитов Groq. Мобильные камеры и Safari на реальных устройствах ещё не прошли полную проверку.
